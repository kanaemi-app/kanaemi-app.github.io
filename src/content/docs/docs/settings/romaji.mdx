かなモードで打った文字を何にするかは、ローマ字の表で決まります。Kanaemi は、いくつかの表を上から順に重ねて 1 つの表にします。

## 用意された表

| 名前 | 中身 |
| --- | --- |
| `full-width` | 英字を除く ASCII の印字可能な文字を全角にする |
| `hepburn` | ヘボン式 |
| `kunrei` | 訓令式 |
| `input-aids` | ヘボン式と訓令式では書き分けられない字や書けない字と、日本語の句読点 |
| `z-symbols` | `z` に続けて打つ記号 |
| `azik` | AZIK。ふつうのローマ字の表に重ねて使う |

既定では `azik` 以外を重ねます。

```toml
[romaji]
tables = ["full-width", "hepburn", "kunrei", "input-aids", "z-symbols"]
```

書いた一覧が、既定の重ね方の代わりになります。同じ入力の規則がいくつかの表にあれば、後に書いた表のものが使われます。

`azik` を使うときは、<kbd>;</kbd> の割り当てを変える必要があります。[キーバインド](/docs/settings/keys/#azik-で使う) を見てください。

## 自分の表を足す

[設定のフォルダ](/docs/settings/folder/) の `romaji` フォルダに表のファイルを置き、一覧にファイル名で書きます。用意された表と同じ名前なら、用意された表を使います。

```toml
[romaji]
tables = ["full-width", "hepburn", "kunrei", "input-aids", "z-symbols", "my.tsv"]
```

表は、1 行に 1 つの規則をタブで区切って書きます。`!` で始まる行は、それまでの表にあった規則を消します。

```tsv
# 自分の表
z-	〜
wi	ゐ
we	ゑ
!1
```

書き方の詳しいことは [ローマ字の表の形式](/docs/reference/romaji-table/) にあります。

## 表にないとき

打った文字がどの規則にもならないときは、次のように扱います。

- `n` に続けて打った文字で規則が作れなければ、`n` は「ん」（`nka` → んか）。確定のときに残った `n` も「ん」。
- 母音と `n` 以外の同じ英小文字を 2 つ続けると「っ」（`kka` → っか）。
- どの規則にもならない英小文字は捨てる。ただし、読みの外で確定するときに残った打ちかけは、打ったとおりに確定する（`arew` のあと確定すると「あれw」）。
- 表にない文字（英大文字を含む）は、打ったとおりに確定する。

<Since feature="keep-unfinished" />

読みの外の打ちかけも捨てたいときは、`keep_unfinished` を `false` にします（`arew` で「あれ」）。読みの中の打ちかけは、いつも捨てます。

```toml
[romaji]
keep_unfinished = false
```

## Space を表で決める

<Since feature="romaji-space" />

規則の入力には、空白も書けます。かなモードで打つ Space は、表に空白を入力に含む規則があれば、文字のキーと同じに表を通ります。SKK のように `z` に続けた Space で全角の空白を打つなら、入力を「`z` と空白」、出力を「全角の空白」にした規則を書きます。

- 空白を入力に含む規則が表にあると、何も打っていないかなモードの Space も表を通ります。どの規則にもならない空白は、表にない文字と同じく、打ったとおりに確定します。
- 読みや候補を選んでいるときの Space は、ふだんどおりキーの割り当て（変換・次の候補）に働きます。
- ただし、ローマ字の打ちかけの続きとして規則を作るキーは、Space に限らず、キーの割り当てより先に表を通ります。読みの中でも、`z` を打ったあとの Space は、変換ではなく、その規則を打ちます。<Since feature="unfinished-romaji-first" />
