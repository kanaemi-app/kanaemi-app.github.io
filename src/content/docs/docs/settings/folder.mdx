Kanaemi の設定、辞書、登録した語は、すべて 1 つのフォルダに入っています。このフォルダを別のマシンにコピーすれば、同じ設定で使えます。

| OS | 場所 |
| --- | --- |
| macOS | `~/Library/Application Support/kanaemi/` |
| Windows | `%APPDATA%\kanaemi\` |
| Linux | `$XDG_CONFIG_HOME/kanaemi/`（なければ `~/.config/kanaemi/`） |

フォルダがなければ、Kanaemi が作ります。

## 中身

| ファイル | 中身 |
| --- | --- |
| `config.toml` | [設定ファイル](/docs/settings/config/) |
| `custom.tsv` | ユーザーカスタム辞書。[登録した語](/docs/usage/register/) と、出さないようにした語が入る |
| `dictionaries/` | [辞書](/docs/dictionaries/) のファイル。中にフォルダを作ってもよい |
| `romaji/` | 自分で書いた [ローマ字の表](/docs/settings/romaji/) |
| `functions/` | 自分で書いた [関数](/docs/settings/functions/)（Luau のファイル） |
| `ranking.model` | [並べ替えのモデル](/docs/usage/candidates/#並び方)。基本辞書と組で入る。なくてもよい |
| `selections.tsv` | [何度も選んだ候補](/docs/usage/candidates/#並び方) の記録。Kanaemi が作る |

利用者が打った語を含むファイル（`custom.tsv`・`selections.tsv`）は、Kanaemi が持ち主だけ読み書きできるようにして作ります。この 2 つは、[ほかの場所にも置けます](#打った語を含むファイルをほかの場所に置く)。

## 打った語を含むファイルをほかの場所に置く

<Since feature="files" />

ユーザーカスタム辞書（`custom.tsv`）と、何度も選んだ候補の記録（`selections.tsv`）は、設定のフォルダの外にも置けます。たとえばユーザーカスタム辞書を iCloud Drive などの同期フォルダに置けば、ほかのマシンでも同じ登録を使えます。設定のフォルダごと同期しなくても済むので、マシンごとの記録や、別に管理している `config.toml` は混ざりません。

[設定ファイル](/docs/settings/config/) の `[files]` に、それぞれのファイルの場所を書きます。

```toml
[files]
custom = "~/Sync/kanaemi/custom.tsv"
selections = "selections.tsv"
```

- 絶対パスか、設定のフォルダからの相対パスで書きます。先頭の `~` はホームフォルダです。
- 書かなければ、設定のフォルダの `custom.tsv`・`selections.tsv` です。

同期フォルダの場所が OS ごとに違うときは、`[files.macos]`・`[files.windows]`・`[files.linux]` に書きます。動いている OS の表が、`[files]` に勝ちます。書いていないファイルは `[files]` の場所のままです。

```toml
[files.macos]
custom = "~/Library/Mobile Documents/com~apple~CloudDocs/kanaemi/custom.tsv"

[files.windows]
custom = "~/iCloudDrive/kanaemi/custom.tsv"
```

- 場所を変えても、前の場所のファイルは動かしません。今の `custom.tsv` を使い続けるなら、新しい場所へ自分で移してください。新しい場所にファイルがなければ、空から始めます。
- 書いたフォルダがなければ、Kanaemi はフォルダを作りません。そのあいだは空として扱い、登録した語や選んだ候補はその場では効きます。フォルダができたら、そこに書きます。
- フォルダがない・読めない・書けないときは、[設定アプリ](/docs/settings/app/#辞書) の「辞書」がそう示します。
- 設定のフォルダのほかのファイルの場所と、`dictionaries`・`romaji`・`functions` フォルダの中には置けません。2 つのファイルを同じ場所にもできません。拡張子が `.lock` のファイルにもできません。書けば、その設定は飛ばします。
- 書き換えるときに使う作業用のファイル（`.lock` など）は、そのファイルと同じフォルダに作ります。
- 別のマシンで同じときに登録したときの食い違いは、同期の仕組みに任せます。
- iCloud Drive の「Mac のストレージを最適化」が有効だと、ファイルの中身が Mac から消されることがあります。そのあいだ、Kanaemi は登録した語を読めません。同期フォルダのファイルは、マシンに残しておく設定にしてください。

## ファイルを変えたとき

ファイルを書き換えたら、入力欄をクリックし直してください。Kanaemi は、入力欄にフォーカスが入るときに、変わったファイルだけを読み直します。Kanaemi を起動し直す必要はありません。

## ログ

うまく動かないときは、ログを見ると手がかりがあります。ログは設定のフォルダの外にあります。

| OS | 場所 |
| --- | --- |
| macOS | `~/Library/Logs/kanaemi.log` |
| Windows | `%LOCALAPPDATA%\kanaemi\kanaemi.log` |
| Linux | `$XDG_STATE_HOME/kanaemi/kanaemi.log`（なければ `~/.local/state/kanaemi/kanaemi.log`） |

[設定アプリ](/docs/settings/app/) でも、ログの末尾を見られます。

ログには、Kanaemi に届いたキーと、Kanaemi がそれにどう応えたかを書きます。打った文字（読み・候補・確定した文字列・文字のキー）は、ひらがな・カタカナ・漢字・英字・数字の種類だけを残して伏せます。ファイルの場所は、ホームフォルダを `~` と書きます。不具合の報告にログを付けても、打った語や名前は伝わりません。ただし、[自分で書いた関数](/docs/settings/functions/) が `print` で出したものは、そのまま書きます。

ログは大きくなると新しく書き始め、それまでのログをいくつか残します。
