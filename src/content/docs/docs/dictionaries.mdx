Kanaemi は、[設定のフォルダ](/docs/settings/folder/) の `dictionaries` フォルダに置いた辞書で変換します。辞書がなくても動きますが、変換しても候補が出ません。

## 公式辞書

Kanaemi のための辞書は、[kanaemi-dict](https://github.com/kanaemi-app/kanaemi-dict) で作っています。

- 基本辞書：ふだんの文章に出てくる語。活用する語と、数を含む語（「3 本」「第 2 回」）も入っています。並べ替えのモデルと組で配っています。まずはこれを入れてください。
- 追加辞書：分野ごとの語。基本辞書にない語だけを持つので、基本辞書に足して使います。

## 設定アプリで入れる

公式辞書は、[設定アプリ](/docs/settings/app/) から入れられます。

<Steps>

1. 設定アプリを開き、「辞書」の画面の「公式の辞書」で「最新の版を確かめる」を押す。

2. 入れたい辞書の「入れる」を押す。まずは基本辞書を入れる。

3. 入力欄をクリックし直す。Kanaemi は、入力欄にフォーカスが入るときに、変わった辞書とモデルを読み直します。

</Steps>

設定アプリは、入れるときに次のことをまとめて行います。

- 辞書を `dictionaries` フォルダの `kanaemi/<名前>/` に置き、[バイナリの辞書](/docs/settings/dictionaries/#テキストとバイナリ) に変換する。
- 基本辞書は、組になっている並べ替えのモデル `ranking.model` と一緒に入れる。
- [辞書の一覧](/docs/settings/dictionaries/) に足す。基本辞書は公式の追加辞書より先に、追加辞書は最後に並べる。
- 落としたファイルが配る側の目録と合うときだけ入れる。合わなければ何も変えず、そのわけを示す。

設定アプリが通信するのは、「最新の版を確かめる」「入れる」「新しくする」を押したときだけです。Kanaemi そのものは通信しません。

### 新しくする

「最新の版を確かめる」を押すと、辞書ごとに「入れていません」「最新です」「新しい版があります」のどれかが出ます。新しい版がある辞書は、「新しくする」で入れ替えられます。基本辞書は、モデルも一緒に新しくなります。

## 手で入れる

設定アプリを使わずに入れることもできます。ネットにつながらないマシンに入れるときなどに使ってください。

<DictionaryDownloads />

zip を展開すると、辞書の名前のフォルダができます。中には、辞書のファイル `kanaemi-<名前>.tsv` と、ライセンスの `LICENSE`、辞書を作るのに使った素材の表示の `NOTICE` が入っています。基本辞書のフォルダには、並べ替えのモデル `ranking.model` も入っています。

<Steps>

1. 辞書のファイル `kanaemi-<名前>.tsv` を、[設定のフォルダ](/docs/settings/folder/) の中の `dictionaries` フォルダに置く。フォルダがなければ作る。

2. 基本辞書の `ranking.model` を、設定のフォルダに置く。`dictionaries` の中ではなく、`config.toml` と同じところに置きます。

3. 追加辞書も使うときは、[設定ファイル](/docs/settings/config/) に辞書の一覧を書き、基本辞書を先に書く。

   ```toml
   dictionaries = ["custom", "kanaemi-base.tsv", "kanaemi-railway.tsv", "kanaemi-it.tsv"]
   ```

4. 入力欄をクリックし直す。

</Steps>

辞書の一覧を書かないと、Kanaemi は `dictionaries` の中の辞書をファイル名の順に使います。この順では、`kanaemi-2026.tsv` のような追加辞書が基本辞書より先に来ることがあり、先にある辞書の候補ほど前に出やすくなります。

並べ替えのモデルは、組になっている基本辞書と一緒に使うものです。手で基本辞書を新しくしたら、`ranking.model` も同じ zip のものに替えてください。

## ライセンス

公式辞書と並べ替えのモデルは、[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/deed.ja) で配っています。辞書を作るのに使った素材の表示は、配布物の `NOTICE` にあります。設定アプリで入れたときは、辞書と同じフォルダに置かれます。

## 読み込みを速くする

テキストの辞書（`.tsv`）は、[設定アプリ](/docs/settings/app/) でバイナリの辞書（`.kdic`）に変換できます。バイナリの辞書は、中身はテキストの辞書と同じで、読み込みが速く、使うメモリも少なくなります。設定アプリで入れた公式辞書は、はじめからバイナリの辞書になっています。

## SKK の辞書を使う

SKK の辞書（`SKK-JISYO.L` など）は、[設定アプリ](/docs/settings/app/) で取り込めます。設定アプリが Kanaemi の形式に変換し、`dictionaries` に「元の名前.tsv」として置きます。

## 自分で書く

辞書はただのテキストファイルです。1 行に 1 語、読みと表記をタブで区切って書きます。

```tsv
# 自分の辞書
きしゃ	記者
かなえみ	Kanaemi
```

書き方の詳しいことは [テキストの辞書の形式](/docs/reference/text-dictionary/) にあります。
