Kanaemi は、[設定のフォルダ](/docs/settings/folder/) の `dictionaries` フォルダに置いた辞書で変換します。辞書がなくても動きますが、変換しても候補が出ません。

## 公式辞書

Kanaemi のための辞書は、[kanaemi-dict](https://github.com/kanaemi-app/kanaemi-dict) で作っています。

- 基本辞書：ふだんの文章に出てくる語。活用する語と、数を含む語（「3 本」「第 2 回」）も入っています。並べ替えのモデルと組で配っています。まずはこれを入れてください。
- 追加辞書：分野ごとの語。基本辞書にない語だけを持つので、基本辞書に足して使います。

それぞれの辞書の中身と作り方は [公式辞書](/docs/reference/official-dictionaries/) にあります。

## 設定アプリで入れる

公式辞書は、[設定アプリ](/docs/settings/app/) から入れられます。

<Steps>

1. 設定アプリを開き、「辞書」の画面の「公式の辞書」で「最新の版を確かめる」を押す。

2. 入れたい辞書の「入れる」を押す。まずは基本辞書を入れる。

3. 入力欄をクリックし直す。Kanaemi は、入力欄にフォーカスが入るときに、変わった辞書とモデルを読み直します。

</Steps>

<Screenshot name="settings-official" alt="「辞書」の画面の「公式の辞書」で「最新の版を確かめる」を押したあと。基本辞書は「最新です」、追加辞書は「入れていません」と出て、それぞれに「入れる」ボタンがある" />

設定アプリは、入れるときに次のことをまとめて行います。

- 辞書を `dictionaries` フォルダの `kanaemi/<名前>/` に置き、[バイナリの辞書](/docs/settings/dictionaries/#テキストとバイナリ) に変換する。
- 基本辞書は、組になっている並べ替えのモデル `ranking.model` と一緒に入れる。
- [辞書の一覧](/docs/settings/dictionaries/) に足す。基本辞書は公式の追加辞書より先に、追加辞書は最後に並べる。
- 落としたファイルが配る側の目録と合うときだけ入れる。合わなければ何も変えず、そのわけを示す。

設定アプリが通信するのは、「最新の版を確かめる」「入れる」「新しくする」を押したときだけです。Kanaemi そのものは通信しません。

設定アプリを使わずに入れるときは、[公式辞書を手で入れる](/docs/reference/official-dictionaries/#手で入れる) を見てください。

### 新しくする

「最新の版を確かめる」を押すと、辞書ごとに「入れていません」「最新です」「新しい版があります」のどれかが出ます。新しい版がある辞書は、「新しくする」で入れ替えられます。基本辞書は、モデルも一緒に新しくなります。

## ライセンス

公式辞書と並べ替えのモデルは、[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/deed.ja) で配っています。辞書を作るのに使った素材の表示は、配布物の `NOTICE` にあります。設定アプリで入れたときは、辞書と同じフォルダに置かれます。ほかの一覧から取った項目の条件は、[公式辞書のライセンス](/docs/reference/official-dictionaries/#ライセンス) にあります。

## 読み込みを速くする

テキストの辞書（`.tsv`）は、[設定アプリ](/docs/settings/app/) でバイナリの辞書（`.kdic`）に変換できます。バイナリの辞書は、中身はテキストの辞書と同じで、読み込みが速く、使うメモリも少なくなります。設定アプリで入れた公式辞書は、はじめからバイナリの辞書になっています。

## ほかの IME の辞書を使う

<Since feature="import-export" />

ほかの IME で育てた辞書は、[設定アプリ](/docs/settings/app/) の「辞書」の画面の「ほかの IME の辞書」で取り込めます。取り込んだ辞書は、ユーザーカスタム辞書とは別の辞書として、`dictionaries` フォルダに置きます。

<Screenshot name="settings-import" alt="「辞書」の画面の「ほかの IME の辞書」。形式（macOS など）を選んで「取り込む」「書き出す…」を押す" />

| 形式 | 取り込むもの |
| --- | --- |
| MS-IME | ユーザー辞書ツールの「一覧の出力」で書き出したテキスト |
| Google 日本語入力 | 辞書ツールの「エクスポート」で書き出したテキスト |
| ATOK | 辞書ユーティリティで単語の一覧を書き出したテキスト |
| macOS | macOS で動かしているときは、システム設定の「キーボード」のユーザ辞書（テキスト置換）をそのまま読む。ほかの OS では、その一覧からドラッグして書き出した plist |
| macSKK・AquaSKK・ibus-skk・fcitx5-skk・fcitx5-cskk・CorvusSKK・DDSKK・skkeleton | その SKK のユーザー辞書を、置き場所から探してそのまま読む |
| SKK 辞書 | `SKK-JISYO.L` のような辞書や SKK のユーザー辞書のファイル。文字コードは 1 行目の `coding:` で決まり、ないときは EUC-JP |

<Steps>

1. 「ほかの IME の辞書」で形式を選び、「取り込む」を押す。ファイルを選ぶ形式では、ファイルを選ぶ。

2. 取り込む語と、取り込まないものとそのわけが出る。確かめて「取り込む」を押すと、辞書を置く。やめれば何も書かない。

3. 入力欄をクリックし直す。

</Steps>

- 取り込まないのは、読めない行、Kanaemi で表せない語（Kanaemi で打てない読みの語など）、語を隠す指定（抑制単語）です。取り込んだ辞書では語を隠せないためです。
- 品詞は、Kanaemi の活用型に当たるものだけを使い、ほかは語として移します。
- 取り込んだ辞書の 1 行目の説明に、どこから取り込んだかを書きます。すでにある辞書とユーザーカスタム辞書は書き換えません。
- 文字コードを取り違えているおそれのあるファイル（読めないバイトがある）は、何も取り込みません。
- 取り込んだ辞書は、ほかの辞書と同じに [辞書の一覧](/docs/settings/dictionaries/) で並べ、使うかどうかを選べます。

### 書き出す

「書き出す…」で、[登録した語](/docs/usage/register/)（ユーザーカスタム辞書の語）を、選んだ形式でそのまま読み込めるファイルに書き出せます。Kanaemi から別の IME に移るときや、ほかの IME と同じ語を使いたいときに使います。

- 書き出す形式で表せない語は書かず、その数を示します。
- 取り込んだ辞書の語は書き出しません。
- SKK の形式の文字コードは、書き出す先に合わせます。macSKK・AquaSKK・skkeleton・CorvusSKK には UTF-8 で、ibus-skk・fcitx5-skk・fcitx5-cskk・DDSKK と「SKK 辞書」には EUC-JP で書きます。

## 自分で書く

辞書はただのテキストファイルです。1 行に 1 語、読みと表記をタブで区切って書きます。

```tsv
# 自分の辞書
きしゃ	記者
かなえみ	Kanaemi
```

書き方の詳しいことは [テキストの辞書の形式](/docs/reference/text-dictionary/) にあります。
