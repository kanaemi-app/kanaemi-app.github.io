置き場所は、辞書の項目の表記のうち、変換のたびに関数を呼んで埋める部分です。読みの数を好きな書き方で書ける（[数を含む語](/docs/usage/numbers/)）ほか、今日の日付のように、変換するたびに値の変わる語も書けます（[日付や時刻を打つ](/docs/usage/builtin/)）。

```tsv
{}こ	{kanji}個
{}がつ{}にち	{-:date %Y}年{0:kanji}月{1:kanji}日
きょう	{-:date %Y-%m-%d}
```

## 書き方

```
{位置:関数 引数}
```

- 位置：関数に渡すもの（変換元）を選びます。数字なら、読みの数を前から 0, 1, 2 … と数えたその番号の数。空なら次の数（位置を省いた置き場所だけで数える）。`-` なら読み全体。
- 関数：呼ぶ関数の名前。空なら、変換元をそのまま書きます。
- 引数：関数の名前の後ろの最初のスペースより後ろ、`}` の前までの文字列。スペースがなければ、引数はありません。`{`・`}`・`\` は `\{`・`\}`・`\\` と書きます。
- `:` のない `{関数 引数}` は、`{:関数 引数}` と同じです。

| 書き方 | 意味 |
| --- | --- |
| `{}` | 次の数をそのまま書く |
| `{kanji}`・`{:kanji}` | 次の数を `kanji` で書く |
| `{1:kanji}` | 2 つ目の数を `kanji` で書く |
| `{1:}` | 2 つ目の数をそのまま書く |
| `{-:}` | 読み全体をそのまま書く |
| `{-:date %Y-%m-%d}` | `date` に、読み全体と `%Y-%m-%d` を渡す |

読みには数の置き場所 `{}` だけを書き、位置・関数・引数は書きません。

次の行は無効です。

- 位置の番号が、読みの `{}` の数以上。
- 位置を省いた置き場所が、読みの `{}` より多い。
- 位置が、数字・`-`・空のどれでもない。

## 埋め方

- 関数には、変換元を打ったまま渡します。数字を半角にするなどの変換はしません。
- 関数がないとき、失敗したとき、値を返さなかったときは、その項目から候補を作りません。
- 送り仮名を示して変換したときは、置き場所のある語から候補を作りません。
- 確定の記録には、埋めたあとの表記ではなく、置き場所のままの項目を残します。埋めた値が変わっても（日付が変わっても、別の数を打っても）、同じ項目には同じ記録が効きます。

## 組み込みの関数

Kanaemi に入っている関数です。[設定](/docs/settings/config/#書ける設定) の `[functions] disabled` に `"builtin:名前"` と書くと使わなくなり、同じ名前の関数を [自分で足す](/docs/settings/functions/) と、そちらを使います。

### 数の書き方

どれも引数を使わず、変換元が数でなければ候補を作りません。

| 名前 | 書き方 | 例（12） | 例（2026） |
| --- | --- | --- | --- |
| （なし） | 打ったまま | 12 | 2026 |
| `half-num` | 半角の数字 | 12 | 2026 |
| `wide-num` | 全角の数字 | １２ | ２０２６ |
| `kanji-num` | 漢数字を 1 けたずつ。0 は 〇 | 一二 | 二〇二六 |
| `kanji` | 位取りした漢数字 | 十二 | 二千二十六 |
| `daiji` | 位取りした大字 | 壱拾弐 | 弐千弐拾六 |
| `grouped-num` | 3 けたごとに `,` を入れた半角の数字 | 12 | 2,026 |

### 年

| 名前 | 書くもの | 例 |
| --- | --- | --- |
| `wareki` | 数を西暦の年として、和暦で書く。その年の大晦日の元号で数える。引数に `1-1` のように月日を書くと、その日の元号で数える | `{wareki}年`（2019）→ 令和1年、`{wareki 1-1}年`（2019）→ 平成31年 |
| `seireki` | 数を、引数の元号の年として、西暦で書く | `{seireki 令和}年`（8）→ 2026年 |
| `eto` | 今年の干支。引数を `支` にすると十二支だけ | 丙午・午 |

### 日時

`date` は、いまの日時を引数の書式で書きます。引数がなければ `%Y-%m-%d` です。書式の前に `+1`・`-2` と書くと日をずらし、`+1y`・`-1y` と書くと年をずらします（`{-:date +1 %Y-%m-%d}` は明日）。

| 書式 | 書くもの | 例 |
| --- | --- | --- |
| `%Y` | 年 | 2026 |
| `%m`・`%d` | 月・日（2 けた） | 03・07 |
| `%-m`・`%-d` | 月・日 | 3・7 |
| `%H`・`%M`・`%S` | 時・分・秒（2 けた） | 09・05・00 |
| `%-H`・`%-M` | 時・分 | 9・5 |
| `%-I`・`%p` | 12 時間制の時、午前か午後 | 9・午前 |
| `%a` | 曜日 | 水 |
| `%E`・`%N` | 元号、元号の年 | 令和・8 |
| `%z`・`%:z` | UTC との時差 | +0900・+09:00 |
| `%s` | 1970-01-01（UTC）からの秒 | 1791331200 |
| `%%` | `%` | % |

書式のほかの文字は、そのまま書きます。

### 毎回違う値

| 名前 | 書くもの |
| --- | --- |
| `uuid` | UUID（第 4 版） |
| `ulid` | ULID |
| `random` | 引数の 2 つの数のあいだの整数を 1 つ（`{-:random 1 6}`） |
| `choice` | 引数にスペースで区切って並べた語から 1 つ（`{-:choice 表 裏}`） |
