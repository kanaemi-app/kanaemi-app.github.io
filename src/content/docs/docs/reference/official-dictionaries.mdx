公式辞書は、Kanaemi のために [kanaemi-dict](https://github.com/kanaemi-app/kanaemi-dict) で作っている辞書です。ふつうは [設定アプリで入れます](/docs/dictionaries/#設定アプリで入れる)。

- 基本辞書：ふだんの文章に出てくる語の辞書。候補の並べ替えのモデルと組で配っています。
- 追加辞書：分野の語や地名、人名のような、基本辞書にない語だけを持つ辞書。基本辞書の後ろに置いて、基本辞書に足して使います。

## 作り方

- 集めた文章を解析器（Sudachi と SudachiDict）で読み、実際に使われた語から辞書を作ります。読みも解析器が付けたものです。
- 文章は、語を選び、出てきた回数を数え、並べ替えを学習するためにだけ読みます。辞書には読みと表記の組と並び順だけが入り、文章そのものは入りません。
- 漢字一字の読みや記号、地名、人名のように文章からは作れない語だけは、再配布と改変が認められたほかの一覧から取ります。
- よく使われる語ほど、候補の前に出やすいコストになります。
- 並べ替えのモデルは、基本辞書と同じ文章で学習しています。

## 基本辞書

ふだんの文章に出てくる語の辞書です。まずはこれを入れてください。

- 広い分野の文章から作ります。百科事典やニュース、文学作品、法令、Web の文章、プログラミング言語のドキュメントなどです。どの素材かは [使った素材](#使った素材) にあります。
- 文章に出てきた語に加えて、UniDic の語も入れています。文章に出てこない UniDic の語は、文章に出た語より後ろに並びます。
- 活用する語（語幹と活用型）、文章に出た活用形、複合語（平安時代）、ウィキペディアの記事の見出しと語の組（多種多様）、数を含む語（「3 本」「第 2 回」）が入っています。
- 送り仮名を指定して打てるように、送り仮名付きの語（書く、明らか）には送り仮名の区切りを付けた行もあります。
- 標準と違う送り仮名（小い、行なう）は入れていません。[送り仮名の揺れ](#送り仮名の揺れ) の辞書にあります。
- 漢字一字の読み（すで 既）は、Mozc の単漢字の表から取っています。Mozc の表にない字の音読みは、Unicode の Unihan データベースから取っています。どれも語より後ろに並びます。
- 取った一覧の条件：Mozc は BSD-3-Clause、Unihan は Unicode License v3。

### 並べ替えのモデル

基本辞書の zip には、候補の並べ替えのモデル `ranking.model` が入っています。基本辞書と同じ文章で学習したもので、組になっている基本辞書と一緒に使います。

## 分野の辞書

- 曖昧さ回避の記事は使いません。
- 記事の見出しのうち、本文に語として出るもの（解析器がいくつかの語に分けてしまう複合語）も入れます。読みは記事の本文から取ります。
- 基本辞書と同じ語は持ちません。

## 法律

[e-Gov 法令検索](https://laws.e-gov.go.jp/) が配る法令の本文から作ります。基本辞書と同じ語は持ちません。

## その年の新語

その年に新しく使われだした語の辞書です。年ごとに作ります。

- その年に日本語版ウィキペディアで新しく作られた記事の見出しを候補にします。記事が作られた年は、記事の番号（ページ ID）で分けます。その年の最初に作られた記事の番号から、次の年の最初の記事の番号の手前までを、その年の記事とします。
- そのうち、その年の Web の文章（はてなブックマークの日ごとの人気エントリーの見出しと要約）に語として出るものを入れます。
- その年の文章で、それより古い文章よりはっきり多く使われる語だけを残します。古くからある語がその年によく出ただけでは入れません。

## 地名

日本郵便の [郵便番号データ](https://www.post.japanpost.jp/zipcode/) の、都道府県・市区町村・町域の表記と読みから作ります。

- 町や字の名前はほとんど文章に出てこないので、文章を通さずに一覧から作ります。
- その地名を持つ郵便番号データの行が多いほど、前に出やすくなります。
- 郵便番号データにない地名（旧地名や通称）は入っていません。
- 郵便番号データの条件：日本郵便は著作権を主張せず、自由に配布できるとしています。

## 人名

[Wikidata](https://www.wikidata.org/) の人物の項目の、日本語のラベルと読み仮名から作ります。

- フルネーム（姓の読みと名の読みを続けたもの）と、姓、名が入っています。
- 姓と名は、表記に漢字を含み、2 人以上の人物が持つものだけです。
- 読み仮名が姓と名に区切られていない人物は、読みがラベル全体に当てはまるときだけ、フルネームとして入れます。
- 読み仮名が姓と名の間に の を挟むときと、源・平・藤原 のような古代の氏で 1600 年より前に生まれた人物は、の を挟んだ読み（みなもとのよりとも）でも引けます。
- Wikidata のサイトリンク（各言語版のウィキペディアなどの記事）が多い人物ほど、前に出やすくなります。日本語版ウィキペディアに記事がある人物は、さらに前に出やすくなります。
- ラベルを姓と名に分けるときに、Mozc の単漢字の表の読みを使っています。
- Wikidata の条件：CC0 1.0。

## 送り仮名の揺れ

標準と違う送り仮名で書いた活用する語（小い、行なう、取組む）だけを集めた辞書です。古い文章を書き写すときや、許容の送り仮名を使うときに足します。

- 基本辞書と同じ文章から、送り仮名の揺れだけを数えて作ります。
- 揺れかどうかは、解析器が揃えた表記と比べて、読みと漢字が同じで送り仮名だけが違うかで決めます。
- 受付、申込 のような活用しない語は、基本辞書に入っています。

## 記号・絵文字・顔文字

記号、絵文字、顔文字は、それぞれ別の辞書です。どれも Mozc の表から、記号や絵文字とその読みを取って作ります。

- 記号：Mozc の記号の表から。変体仮名は入れていません。
- 絵文字：Mozc の絵文字の表から。読みは、Mozc が Unicode CLDR の注釈から作ったものです。
- 顔文字：Mozc の顔文字の表から。
- 読みは、既定のローマ字の表で打てる形に直しています。
- 表の条件：Mozc は BSD-3-Clause。絵文字の読みのもとの Unicode CLDR は Unicode License v3。

## 手で入れる

設定アプリを使わずに入れることもできます。ネットにつながらないマシンに入れるときなどに使ってください。

### ダウンロード

<DictionaryDownloads />

zip を展開すると、辞書の名前のフォルダができます。中には、辞書のファイル `kanaemi-<名前>.tsv` と、ライセンスの `LICENSE`、辞書を作るのに使った素材の表示の `NOTICE` が入っています。基本辞書のフォルダには、並べ替えのモデル `ranking.model` も入っています。

### 置く

<Steps>

1. 辞書のファイル `kanaemi-<名前>.tsv` を、[設定のフォルダ](/docs/settings/folder/) の中の `dictionaries` フォルダに置く。フォルダがなければ作る。

2. 基本辞書の `ranking.model` を、設定のフォルダに置く。`dictionaries` の中ではなく、`config.toml` と同じところに置きます。

3. 追加辞書も使うときは、[設定ファイル](/docs/settings/config/) に [辞書の一覧](/docs/settings/dictionaries/) を書き、基本辞書を先に書く。

   ```toml
   dictionaries = ["custom", "kanaemi-base.tsv", "kanaemi-railway.tsv", "kanaemi-it.tsv"]
   ```

4. 入力欄をクリックし直す。

</Steps>

辞書の一覧を書かないと、Kanaemi は `dictionaries` の中の辞書をファイル名の順に使います。この順では、`kanaemi-2026.tsv` のような追加辞書が基本辞書より先に来ることがあり、先にある辞書の候補ほど前に出やすくなります。

並べ替えのモデルは、組になっている基本辞書と一緒に使うものです。手で基本辞書を新しくしたら、`ranking.model` も同じ zip のものに替えてください。
