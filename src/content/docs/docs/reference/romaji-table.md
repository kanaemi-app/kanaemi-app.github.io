---
title: ローマ字の表の形式
description: かなモードで打った文字を何にするかを決める表の書き方。
---

用意された表も、自分で書く表も、この形式のファイルです。使い方は [ローマ字の表](/docs/settings/romaji/) を見てください。

## ファイル

- 文字コードは UTF-8（BOM は無視する）。行末は LF。CR LF も受け付ける。拡張子は `.tsv`。
- 空行と、`#` で始まる行は無視する。
- 1 行目が `#` で始まるなら、その行の残りはファイルの説明。
- それ以外の行は、タブで区切った規則行。

## 規則行

```
入力<TAB>出力
!入力
```

- 入力は、ASCII の印字可能な文字（`!` から `~` まで）で、空にできない。
- 出力は空にできない。
- `!` で始まる行は、その入力の規則を消す。

```tsv
shi	し
z-	〜
!1
```

## エスケープ

| 書き方 | 意味 | 使えるところ |
| --- | --- | --- |
| `\\` | `\` | すべてのフィールド |
| `\#` | `#` | 入力の先頭 |
| `\!` | `!` | 入力の先頭 |

これ以外の `\` を含む行は無効です。

## 重ね方

- 表は、空の表に、選んだファイルを順に当てはめて作る。ファイルの中では上の行から順に当てはめる。
- 同じ入力の規則は、後に当てはめたものが使われる。消した入力も、後の行で足し直せる。
- 打った入力が、ある規則と一致し、別の規則の始まりにもなっているときは、続きを待つ。続きでどの規則にもならないときや確定するときは、いちばん長く一致する規則を使い、残りは続けて当てはめる。
- 無効な行は飛ばす。
