---
title: テキストの辞書の形式
description: 人が書き、配り、やり取りするための辞書ファイルの書き方。
---

テキストの辞書は、人が書き、配り、やり取りするための辞書の形式です。Kanaemi はこの形式のまま読めます。ユーザーカスタム辞書（`custom.tsv`）もこの形式です。

## ファイル

- 文字コードは UTF-8（BOM は無視する）。行末は LF。CR LF も受け付ける。拡張子は `.tsv`。
- 空行と、`#` で始まる行は無視する。
- 1 行目が `#` で始まるなら、その行の残りはファイルの説明。[設定アプリ](/docs/settings/app/) に出る。
- それ以外の行は、タブで区切った項目行。

## 項目行

```
読み<TAB>表記
読み<TAB>表記<TAB>活用型
読み<TAB>表記<TAB>活用型<TAB>コスト
```

- 読みと表記は空にできない。活用型とコストは空でもよい。
- コストは 0 から 4294967295 までの整数。小さいほど前に並ぶ。
- フィールドの数がこれ以外の行は無効。

### 語

```tsv
きしゃ	記者
```

### 活用する語

読みと表記は語幹（どの形でも変わらない部分）、活用型は UniDic の活用型の名前（`五段-カ行`・`上一段-ア行`・`サ行変格`・`形容詞` など）。

```tsv
か	書	五段-カ行
たべ	食べ	下一段-バ行
```

これだけで、「かく」「かいた」「かかない」などの読みから「書く」「書いた」「書かない」が出ます。語幹の後ろに付けられる読みは 4 かなまでです。知らない活用型の行は無効です。

### 送り仮名付きの語

読みの `*` で送り仮名の始まりを示します。`*` の後ろは送り仮名の最初のかな 1 文字で、表記はそのかなで終わります。

```tsv
か*く	書く
```

### 数を含む語

読みの `{}` は数の置き場所、表記の `{}`・`{名前}` は数の書き方です（[数を含む語](/docs/usage/numbers/#数を含む語を登録する)）。

```tsv
{}こ	{}個
{}こ	{kanji}個
{}がつ{}にち	{kanji}月{kanji}日
```

活用型や送り仮名は付けられません。

### 出さない語

ユーザーカスタム辞書だけで使えます。読みの先頭の `!` は、その（読み, 表記）をどの辞書の候補にも出さないことを表します。

```tsv
!きしゃ	汽車
```

## エスケープ

| 書き方 | 意味 | 使えるところ |
| --- | --- | --- |
| `\\` | `\` | すべてのフィールド |
| `\t` | タブ | すべてのフィールド |
| `\n` | 改行 | すべてのフィールド |
| `\#` | `#` | 読みの先頭 |
| `\!` | `!` | 読みの先頭 |
| `\*` | `*` | 読み |
| `\{` | `{` | 読みと表記 |

これ以外の `\` を含む行は無効です。

## Kanaemi が読むときの決まり

- 無効な行は飛ばします。[設定アプリ](/docs/settings/app/) で、読めない行とそのわけを見られます。
- 同じ（読み, 表記, 活用型）の行が複数あれば、後の行が使われます。
- コストを書かない行は、同じ読みの項目のうち後に書いたものほど前に並びます。

## SKK の辞書から

SKK の辞書は、[設定アプリ](/docs/settings/app/) でこの形式に変換して取り込めます。送りありの見出し（`かk /書/`）は送り仮名付きの語に、`#` を含む見出しは数を含む語になります。S 式の候補と、候補の `;` から後ろ（注釈）は移しません。
