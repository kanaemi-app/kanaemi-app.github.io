Kanaemi（かなえみ）は、macOS・Windows・Linux で同じように使える日本語入力（IME）です。読みの区切りを自分で決めて 1 語ずつ確定する [SKK](http://openlab.jp/skk/) の打ち方をもとにしています。

## SKK と同じところ

- ふだんはローマ字で打ったかなが、その場で確定します。
- 漢字にしたい語だけ、<kbd>;</kbd> から打ちはじめて変換します。
- 候補がなければ、その場で語を登録して確定まで進めます。

## SKK と違うところ

- 読みは大文字ではなく <kbd>;</kbd> で示すので、`;1ko` →「1個」のように数字から始まる語も変換できます。数字の専用モードも abbrev モードも要りません。
- モードはかなと ABC だけです。カタカナや英数は、確定するときに選びます。
- 読みを始めるキーは、修飾キーの単独押しや Space の押さえたままにも割り当てられ、Sticky Shift や [SandS](/docs/settings/keys/#sands-で使う) のように打てます。
- 日付や和暦のような語は、辞書から安全な [Luau の関数](/docs/settings/functions/) を呼んで作ります。
- 辞書は 1 行 1 語の [TSV](/docs/reference/text-dictionary/) で、エディタでそのまま直せます。
- 活用した語は、送り仮名を示さなくても変換できます（`;kaita` →「書いた」）。
- 候補は、その入力欄でよく選ぶ表記が前に出ます。
- キーの意味も変換の結果も、OS によらず同じです。

## 動く環境

| OS | 仕組み |
| --- | --- |
| macOS（Apple シリコン） | InputMethodKit |
| Windows | Text Services Framework（x64・arm64） |
| Linux | IBus（GNOME などのデスクトップ） |
