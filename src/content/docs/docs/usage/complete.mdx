読みを打っている途中で <kbd>Tab</kbd> を押すと、いま打った読みを、それで始まるより長い読みに置き換えます（`かく` → `かくにん`）。長い読みを最後まで打たずに済みます。

補完は、<kbd>Tab</kbd> を押したときだけ行います。打っているそばから候補を出すことはありません。

## 補完する

```
;kaku → Tab → ›かくにん → Tab → ›かくご → … → ›かく
```

1. <kbd>;</kbd> で読みを始め、読みの始めを打つ。<kbd>;kaku</kbd> → <span class="preedit">›かく</span>
2. <kbd>Tab</kbd> を押す。読みが置き換わり、補完の読みの一覧が出る。→ <span class="preedit">›かくにん</span>
3. 続けて <kbd>Tab</kbd> を押すと、次の読みに置き換わる。最後の次は、打った読みに戻る。<kbd>Shift</kbd>＋<kbd>Tab</kbd> は逆向きに回る。
4. 置き換えた読みは、打った読みと同じに扱われる。<kbd>Space</kbd> で変換も、<kbd>Enter</kbd> でかなのまま確定も、打ち足しもできる。

送り仮名の始まりを付けた読み（<kbd>;ka;</kbd>）は補完しません。

## 補完の読みの一覧

<Since feature="completion-list" />

補完しているあいだは、補完の読みを候補と同じように一覧に出します。読みごとに、変換したとき最初に出る候補を添え、選んでいる読みのほかの候補も出します。

| キー | すること |
| --- | --- |
| <kbd>Tab</kbd>・<kbd>↓</kbd> | 次の読み |
| <kbd>Shift</kbd>＋<kbd>Tab</kbd>・<kbd>↑</kbd> | 前の読み |
| <kbd>1</kbd>〜<kbd>9</kbd> | 出ているページの、その番号の読みにする |
| <kbd>Ctrl</kbd>＋<kbd>N</kbd>・<kbd>Ctrl</kbd>＋<kbd>P</kbd> | 次・前のページの最初の読み。端のページの先は、打った読みに戻る |
| <kbd>Enter</kbd> | 一覧を閉じて、置き換えた読みのまま残る。もう一度押すと、かなのまま確定する |
| <kbd>Esc</kbd> | 一覧を閉じて、打った読みに戻る。もう一度押すと、読みを取り消す |

ここにないキーは、[読みを打っているとき](/docs/usage/convert/#読みを打っているあいだ) と同じに働きます。ほかのキーを押すと、補完は終わります。番号で読みを選んだときは、補完が続きます。

## 変換してから選び直す

補完した読みを変換しても、補完は続きます。候補を選んでいるときに <kbd>Tab</kbd> を押すと、読みに戻って次の読みに進みます。

```
;kaku → Tab → ›かくにん → Space → »確認 → Tab → ›かくご
```

<kbd>Esc</kbd> は、一つ前に戻ります。

```
»確認 → Esc → ›かくにん（一覧あり）→ Esc → ›かく → Esc → 取り消し
```

## 出てくる読み

- この入力欄で確定した読みと、[何度も選んだ候補](/docs/usage/candidates/#並び方) の読みを、先に出します。
- そのあとに、辞書の活用しない語の読みを出します。
- 同じ読み・同じ辞書・同じ記録なら、並びはいつも同じです。

## キーを変える

補完の一覧が出ているあいだの割り当ては、設定ファイルの `[keys.completion]` に書きます。補完を始めるキーは、`[keys.reading]` と `[keys.candidates]` の `@complete`・`@complete-previous` です（[キーバインド](/docs/settings/keys/)、[既定のキー](/docs/reference/default-keys/#補完の一覧が出ているとき)）。
