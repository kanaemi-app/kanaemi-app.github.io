---
title: 候補を選ぶ
description: 候補を回り、番号で選び、カタカナや英数で確定する。候補の並び方。
---

変換すると、候補を選ぶ場面に入ります。選んでいる候補には `»` の印が付きます。

## 選ぶ

| キー | すること |
| --- | --- |
| <kbd>Space</kbd>・<kbd>↓</kbd>・<kbd>Ctrl</kbd>＋<kbd>N</kbd> | 次の候補。最後の次は [語の登録](/docs/usage/register/) |
| <kbd>Shift</kbd>＋<kbd>Space</kbd>・<kbd>↑</kbd>・<kbd>Ctrl</kbd>＋<kbd>P</kbd> | 前の候補。最初の前は最後 |
| <kbd>1</kbd>〜<kbd>9</kbd> | 出ているページの、その番号の候補を確定する |
| <kbd>Enter</kbd>・<kbd>Ctrl</kbd>＋<kbd>J</kbd> | 選んでいる候補を確定する |
| <kbd>;</kbd> | 選んでいる候補を確定して、次の読みを始める |
| 文字のキー | 選んでいる候補を確定して、その文字を打つ |
| <kbd>Esc</kbd>・<kbd>Ctrl</kbd>＋<kbd>G</kbd> | 読みに戻る |
| <kbd>Backspace</kbd> | 読みに戻り、読みを 1 文字消す |
| <kbd>0</kbd> | その読みで [語を登録する](/docs/usage/register/) |
| <kbd>Shift</kbd>＋<kbd>Delete</kbd> | 選んでいる候補を、以後出さない |

候補の一覧は 9 個ずつのページで出ます。番号はページの中で 1 から振ります。候補が 1 つだけのときは、一覧を出しません。一覧の候補はマウスでも選べます。

## カタカナや英数で確定する

候補の最後には、読みをカタカナ・半角カタカナ・全角英数・半角英数にしたものが付きます。英数は、読みを打ったキーから作ります（`kanji` → ｋａｎｊｉ・kanji）。

ファンクションキーなら、候補を回らずにすぐ確定できます。

| キー | 確定するもの | 例（`;kanji`） |
| --- | --- | --- |
| <kbd>F6</kbd> | ひらがな | かんじ |
| <kbd>F7</kbd> | カタカナ | カンジ |
| <kbd>F8</kbd> | 半角カタカナ | ｶﾝｼﾞ |
| <kbd>F9</kbd> | 全角英数 | ｋａｎｊｉ |
| <kbd>F10</kbd> | 半角英数 | kanji |
| <kbd>無変換</kbd> | カタカナを選ぶ（確定はしない） | »カンジ |

## 並び方

並べ替えのモデル（基本辞書と組の `ranking.model`）が設定のフォルダにあれば、候補をモデルの点数の順に並べます。モデルは、読みと表記、候補が来た辞書、この入力欄で確定した語と直前に確定した文字などから点数を付けます。モデルは、[設定アプリで基本辞書を入れる](/docs/dictionaries/#設定アプリで入れる) と一緒に入ります。

モデルがなければ、次の順に並べます。

1. この入力欄で、同じ読みに対して最後に確定した表記
2. この入力欄で確定したことのある表記
3. それ以外。辞書の優先度の順、同じ辞書の中ではよく使う語から

さらに、その入力欄でその読みをまだ確定していなければ、何度も選んできた候補が先頭に出ます。1 度選んだだけでは順は変わらず、古い選択ほど順への影響が小さくなります。

- 入力欄の中の記録（1・2）は、フォーカスが移ると捨てます。
- 何度も選んだ候補の記録は、[設定のフォルダ](/docs/settings/folder/) の `selections.tsv` に残ります。読みと表記だけを残し、いつ選んだかは残しません。[設定アプリ](/docs/settings/app/) で消せます。
- パスワード欄と、ブラウザのプライベートウィンドウのように記録しないよう求める入力欄では、どちらの記録も取りません。

同じ読み・同じ記録なら、並びはいつも同じです。打つたびに順が変わることはありません。

## 出さないようにする

<kbd>Shift</kbd>＋<kbd>Delete</kbd> で、選んでいる候補をその読みで以後出さないようにできます。どの辞書の候補にも使えます。戻すときは [設定アプリ](/docs/settings/app/) を使います。

読みから作った候補（カタカナや英数）は、出さないようにできません。
