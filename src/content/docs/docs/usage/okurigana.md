---
title: 送り仮名
description: 読みの途中の ; で送り仮名の始まりを示し、その場で変換する。
---

読みの途中で <kbd>;</kbd> を押すと、そこが送り仮名の始まりになります。送り仮名の最初のかなを打った時点で、すぐ変換します。

| 打つキー | 結果 |
| --- | --- |
| `;ka;ku` | <span class="preedit is-candidate">»書く</span> |
| `;ta;be` | <span class="preedit is-candidate">»食べ</span> |
| `;kan;ji` | <span class="preedit is-candidate">»感じ</span> |

送り仮名を示さなくても、[活用した語は読みのまま変換できます](/docs/usage/convert/#活用した語)。示すと、候補が送り仮名で終わるものに絞られ、送り仮名の始まりで分かれる候補が前に出ます。

[SandS で使う](/docs/settings/keys/#sands-で使う) 設定にしてあれば、Space を押さえたまま送り仮名の最初のキーを押しても、送り仮名の始まりになります。

## 打ちかけを続ける

送り仮名の「まとまり」は、ローマ字の規則 1 つ分です（`kya` → きゃ、`tta` → っ）。まとまりを打ったところで変換し、余ったローマ字は候補の後ろに残ります。

```
;mo;tt   → »持っ t
```

打ちかけの続きを打って、かなが仕上がると、仕上がったかなを送り仮名に足して変換し直します。

```
;ka;tt   → »勝っ t
;ka;tta  → »勝った（ほかに「買った」など）
```

送り仮名が「った」になってから候補を選び直すので、「っ」だけでは分けられなかった語も、続くかなで絞られます。選んでいた候補は、かなを足した形が候補にあれば、そのまま選んでいます。

打ちかけを続けない文字を打つと、選んでいる候補を確定して、その文字を打ちます。

## 消す・戻る

- <kbd>Backspace</kbd> は、打ちかけ、送り仮名、送り仮名の始まりの順に消します。打ちかけの続きで足したかなは、打ちかけに戻して消し、変換し直します（<span class="preedit is-candidate">»勝った</span> → <span class="preedit is-candidate">»勝っ t</span>）。
- 候補を選んでいるときの <kbd>Esc</kbd> は、送り仮名を残したまま読みに戻ります。

## 決まりごと

- 送り仮名の始まりは、カーソルが読みの末尾にあるときだけ付けられます。
- 送り仮名を付けたあとの <kbd>;</kbd> は何もしません。
- ローマ字の打ちかけがあれば、先にかなにしてから送り仮名の始まりを付けます（`;kan;ji` は読み「かん」と送り仮名「じ」）。
