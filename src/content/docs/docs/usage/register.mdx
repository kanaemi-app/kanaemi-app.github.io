候補に打ちたい語がなければ、その場で登録できます。登録すると、そのまま確定まで進むので、打つのを中断せずに続けられます。

## 登録する

1. 候補を最後まで回るか、候補を選んでいるときに <kbd>0</kbd> を押す。登録の場面に入る。

   <span class="preedit">»かなえみ « </span>

2. 登録する文字列を、ふだんどおりに打つ。<kbd>;</kbd> で読みを始めて変換することも、<kbd>英数</kbd> や左の <kbd>Shift</kbd> で ABC モードにして英字を打つこともできる。

   <span class="preedit">»かなえみ « Kanaemi</span>

3. <kbd>Enter</kbd> で登録して確定する。

<Screencast name="register" alt=";kanaemi を変換し、0 で登録の場面に入る。コピーしておいた「Kanaemi」を Ctrl+Y で登録する文字列に貼り、Enter で登録して確定する。もう一度 ;kanaemi を変換すると、登録した Kanaemi が候補に出る" />

登録した語は、[設定のフォルダ](/docs/settings/folder/) の `custom.tsv`（ユーザーカスタム辞書）に入ります（[ほかの場所にも置けます](/docs/settings/folder/#打った語を含むファイルをほかの場所に置く)）。あとから [設定アプリ](#登録した語を直す) で直すことも、テキストファイルとして手で直すこともできます。

読みにかながないとき（<kbd>;pdf</kbd>）は、登録の場面に入りません。語は読みのかなで登録するためです。

## 登録の場面のキー

| キー | すること |
| --- | --- |
| <kbd>Enter</kbd>・<kbd>Ctrl</kbd>＋<kbd>J</kbd> | 登録して確定する。文字列が空なら、登録せずに読みに戻る |
| <kbd>Esc</kbd>・<kbd>Ctrl</kbd>＋<kbd>G</kbd> | 登録せずに読みに戻る |
| <kbd>;</kbd> | 登録する文字列の中で、読みを始める |
| 左の <kbd>Shift</kbd>（単独）・<kbd>英数</kbd>・<kbd>無変換</kbd> | ABC モードへ |
| 右の <kbd>Shift</kbd>（単独）・<kbd>かな</kbd>・<kbd>変換</kbd> | かなモードへ |
| <kbd>Ctrl</kbd>＋<kbd>Y</kbd>・<kbd>Ctrl</kbd>＋<kbd>V</kbd> | クリップボードの文字列を貼る（[下を見る](#ほかの所から写して登録する)） <Since feature="paste" /> |

登録の場面にいるあいだは、カーソルの近くに「辞書登録中」と出ます。登録する文字列を打っているときは、登録せずに抜けるキーと、貼り付けるキーも添えます。

登録する文字列には、空白も打てます。

### モードごとに分ける

<Since feature="registration-modes" />

登録の場面のキーは、かなモードと ABC モードとで分けて決めることもできます。たとえば、英字を打っているときだけ <kbd>;</kbd> を文字として打つ、といった割り当てです（[登録の場面をモードごとに分ける](/docs/settings/keys/#登録の場面をモードごとに分ける)）。

## ほかの所から写して登録する

<Since feature="paste" />

登録したい語をほかの所でコピーしておけば、登録する文字列を打っているときに <kbd>Ctrl</kbd>＋<kbd>Y</kbd> か <kbd>Ctrl</kbd>＋<kbd>V</kbd> で、カーソルの位置に貼れます。

アプリのメニューや、アプリ自身の貼り付けのキーで貼ると、登録する文字列ではなく、入力欄に入ってしまいます。macOS の <kbd>Cmd</kbd>＋<kbd>V</kbd> は、アプリが自分で貼るので、既定には入れていません。[キーバインド](/docs/settings/keys/) で `@paste` に割り当てることはできますが、そのキーでは貼れないことが多く、設定アプリが警告を出します。

## 送り仮名付きの語

送り仮名を示した読み（<kbd>;nu;nu</kbd>）で登録すると、送り仮名付きの語として登録します。登録する文字列が送り仮名で終わっていなければ、送り仮名を足して登録します（「x」と打てば「xぬ」）。

## 登録の中でさらに登録する

登録する文字列を打っている途中で変換して、そこでも候補がなければ、さらに登録の場面に入れます。内側で登録した語は、外側の登録する文字列に入ります。入れ子は 3 段までです。

打ちかけの続きで送り仮名が伸びたとき（<kbd>;ka;tta</kbd> の「った」）は、送り仮名の始まりのかなまでで登録します（<kbd>;ka;tta</kbd> で「勝った」と登録すると `か*っ	勝っ`）。

## 置き場所を書いて登録する

登録する文字列に `{kanji}` や `{-:date %Y-%m-%d}` のような [置き場所](/docs/reference/placeholders/) を書くと、変換のたびに置き場所を埋める語として登録します。読みに数があれば、どの数にも使える項目になります（[数を含む語](/docs/usage/numbers/#数を含む語を登録する)）。登録したときは、置き場所を埋めたものを確定します。

置き場所として読めない文字列は、打ったまま登録します。

## 登録した語を直す

<Since feature="edit-words" />

[設定アプリ](/docs/settings/app/#登録した語) で、登録した語を一覧で見て、足し、直し、消せます。「辞書」の画面で、ユーザー辞書の語を見るところを開きます。

<Screenshot name="settings-words" alt="ユーザー辞書の画面。登録した語が読みと表記で並び、語ごとに「直す」「消す」、下に「語を足す」のボタンがある" />

- 語は、読みと表記で書きます。読みはひらがなで書き、送り仮名のある語は送り仮名の前に `*` を入れます（`か*く`・`書く`）。
- 数の入る語は、読みに `{}` を、表記に `{kanji}` のような [置き場所](/docs/reference/placeholders/) を書きます。
- 活用型やコストを書いた行のように、ここで書けない行は一覧に出ず、変わりもしません。

出さないようにした語は、この一覧ではなく [出さないようにした語](/docs/usage/candidates/#出さないようにする) のところで戻します。
