---
title: 数を含む語
description: 数を含む読みを、数の書き方を選べる候補に変換する。
---

数を含む読みは、数の書き方を選べる候補に変換します。

```
;1ko  →  ›１こ  →  1個・１個・一個 …
;12gatu25nichi  →  12月25日・十二月二十五日 …
```

辞書は、数の書き方ごとに語を持つのではなく、数の代わりに「置き場所」を書いた項目を持ちます。変換のときに、打った数でその置き場所を埋めます。どの数を打っても、同じ項目から候補が出ます。

## 数の書き方

| 書き方 | 例（12） | 例（2026） |
| --- | --- | --- |
| 半角の数字 | 12 | 2026 |
| 全角の数字 | １２ | ２０２６ |
| 漢数字を 1 けたずつ | 一二 | 二〇二六 |
| 位取りした漢数字 | 十二 | 二千二十六 |
| 位取りした大字 | 壱拾弐 | 弐千弐拾六 |
| 3 けたごとに `,` | 12 | 2,026 |

どの書き方の候補が出るかは、辞書の項目によります。公式の基本辞書は、文章でよく使われる書き方の項目を持っています。

## 数の決まり

- 数は、読みの中で続いている数字の並びです。半角と全角が混ざっていてもかまいません。
- `,` や `.` は数を区切ります。`1.5` は 1 と 5 の 2 つの数として扱います。
- 1 つの読みに数がいくつあってもかまいません（`12がつ25にち`）。
- 送り仮名を示したときは、数の項目を使いません。

確定した書き方は、ほかの数を打ったときの並びにも反映されます。同じ入力欄で `;1ko` から「一個」を確定したあとは、`;2ko` でも「二個」が前に出ます。

## 数を含む語を登録する

数のある読みで [語を登録する](/docs/usage/register/) とき、登録する文字列に置き場所を書くと、どの数にも使える項目になります。

| 置き場所 | 書き方 | 例（`007`） |
| --- | --- | --- |
| `{}` | 打ったまま | 007 |
| `{half-num}` | 半角の数字 | 007 |
| `{wide-num}` | 全角の数字 | ００７ |
| `{kanji-num}` | 漢数字を 1 けたずつ | 〇〇七 |
| `{kanji}` | 位取りした漢数字 | 七 |
| `{daiji}` | 位取りした大字 | 七 |
| `{grouped-num}` | 3 けたごとに `,` を入れた半角の数字 | 7 |

- `{}` は、打ったとおりの数字（全角で打てば全角）をそのまま書きます。いつも半角にしたいときは `{half-num}` を使います。
- 先頭の 0 は、`{}`・`{half-num}`・`{wide-num}`・`{kanji-num}` では残し、ほかでは落とします。
- 読みに数が 2 つ以上あるときは、前から順に置き場所に入ります。`{1:kanji}` のように番号を書くと、何番目の数を入れるか選べます（0 から数えます）。

たとえば読み <span class="preedit">›３ばんせん</span> で `{half-num}番線` と登録すると、「3番線」を確定し、以後は `;5bansen` でも「5番線」が出ます。置き場所を書かなければ、打ったままの読み（３ばんせん）で登録します。

置き場所の書き方の詳しいことと、ほかの書き方は [表記の置き場所](/docs/reference/placeholders/) にあります。自分で書き方を足すこともできます（[関数を足す](/docs/settings/functions/)）。
