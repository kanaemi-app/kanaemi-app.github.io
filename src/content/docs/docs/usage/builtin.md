---
title: 日付や時刻を打つ
description: 「きょう」で今日の日付、「いま」で今の時刻。Kanaemi に入っている組み込みの辞書。
---

Kanaemi には、変換するたびに値の決まる語の辞書が入っています。辞書を入れなくても使えます。

```
;kyou  →  2026-10-07・2026/10/07・10月7日・2026年10月7日・令和8年10月7日・10月7日（水）
;ima   →  09:05・9時5分・午前9時5分
```

## 組み込みの辞書

| 辞書 | 読み | 候補 |
| --- | --- | --- |
| `date` | きょう・あした・あさって・きのう・おととい | その日の日付を、いくつかの書き方で（2026-10-07・2026/10/07・10月7日・2026年10月7日・令和8年10月7日・10月7日（水）） |
| | ようび | 今日の曜日（水曜日・水） |
| `time` | いま | 今の時刻（09:05・9時5分・午前9時5分） |
| | にちじ | 今の日時（2026-10-07 09:05:00・2026年10月7日 9時5分） |
| | たいむすたんぷ | ファイル名などに使う日時（20261007-090500・2026-10-07T09:05:00+09:00） |
| | ゆにっくすじかん | 1970-01-01（UTC）からの秒 |
| `year` | ことし・らいねん・さらいねん・きょねん・おととし | その年を西暦と和暦で（2026年・令和8年） |
| | えと | 今年の干支（丙午・午） |
| | `{}ねん`（`;2026nen`） | 西暦の年を和暦で（令和8年） |
| | れいわ・へいせい・しょうわ・たいしょう・めいじ ＋ `{}ねん`（`;reiwa8nen`） | 和暦の年を西暦で（2026年） |
| `random` | あいでぃー・ゆーゆーあいでぃー・ゆーえるあいでぃー | 毎回新しい UUID・ULID |
| | さいころ | 1〜6 のどれか |
| | こいん | 表か裏 |

日時は、そのマシンの時計とタイムゾーンで決まります。

## 並び方と、使わないようにする

組み込みの辞書は、ほかの辞書と同じく [辞書の一覧](/docs/settings/dictionaries/) に並びます。

- 一覧を書かなければ、ほかのすべての辞書のあとに使います。同じ読みの語があれば、ほかの辞書の語が先に並びます。
- 一覧を書くときは、使う組み込みの辞書を `"builtin:date"` のように書きます。書かなかった組み込みの辞書は使いません。
- 一部の候補だけを出さなくしたいときは、ほかの語と同じく [出さないようにできます](/docs/usage/candidates/#出さないようにする)。日付が変わっても、出さないままです。

## 自分で足す

同じ仕組みで、自分の辞書にも値の変わる語を書けます。表記に [置き場所](/docs/reference/placeholders/) を書きます。

```tsv
しめきり	{-:date +7 %-m月%-d日}
```

[語を登録する](/docs/usage/register/) ときに、登録する文字列に置き場所を書いても登録できます（<span class="preedit">»しめきり « {-:date +7 %-m月%-d日}</span>）。置き場所の記号は、ABC モードにして打ちます。
