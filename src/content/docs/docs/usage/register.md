---
title: 語を登録する
description: 候補がなければ、その場で語を登録して確定まで進める。
---

候補に打ちたい語がなければ、その場で登録できます。登録すると、そのまま確定まで進むので、打つのを中断せずに続けられます。

## 登録する

1. 候補を最後まで回るか、候補を選んでいるときに <kbd>0</kbd> を押す。登録の場面に入る。

   <span class="preedit">»かなえみ « </span>

2. 登録する文字列を、ふだんどおりに打つ。<kbd>;</kbd> で読みを始めて変換することも、<kbd>英数</kbd> や左の <kbd>Shift</kbd> で ABC モードにして英字を打つこともできる。

   <span class="preedit">»かなえみ « Kanaemi</span>

3. <kbd>Enter</kbd> で登録して確定する。

登録した語は、[設定のフォルダ](/docs/settings/folder/) の `custom.tsv`（ユーザーカスタム辞書）に入ります。テキストファイルなので、あとから手で直すこともできます。

## 登録の場面のキー

| キー | すること |
| --- | --- |
| <kbd>Enter</kbd>・<kbd>Ctrl</kbd>＋<kbd>J</kbd> | 登録して確定する。文字列が空なら、登録せずに読みに戻る |
| <kbd>Esc</kbd>・<kbd>Ctrl</kbd>＋<kbd>G</kbd> | 登録せずに読みに戻る |
| <kbd>;</kbd> | 登録する文字列の中で、読みを始める |
| 左の <kbd>Shift</kbd>（単独）・<kbd>英数</kbd>・<kbd>無変換</kbd> | ABC モードへ |
| 右の <kbd>Shift</kbd>（単独）・<kbd>かな</kbd>・<kbd>変換</kbd> | かなモードへ |

登録する文字列には、空白も打てます。

## 送り仮名付きの語

送り仮名を示した読み（`;nu;nu`）で登録すると、送り仮名付きの語として登録します。登録する文字列が送り仮名で終わっていなければ、送り仮名を足して登録します（「x」と打てば「xぬ」）。

## 登録の中でさらに登録する

登録する文字列を打っている途中で変換して、そこでも候補がなければ、さらに登録の場面に入れます。内側で登録した語は、外側の登録する文字列に入ります。入れ子は 3 段までです。

打ちかけの続きで送り仮名が伸びたとき（`;ka;tta` の「った」）は、送り仮名の始まりのかなまでで登録します（`;ka;tta` で「勝った」と登録すると `か*っ	勝っ`）。

## 置き場所を書いて登録する

登録する文字列に `{kanji}` や `{-:date %Y-%m-%d}` のような [置き場所](/docs/reference/placeholders/) を書くと、変換のたびに置き場所を埋める語として登録します。読みに数があれば、どの数にも使える項目になります（[数を含む語](/docs/usage/numbers/#数を含む語を登録する)）。登録したときは、置き場所を埋めたものを確定します。

置き場所として読めない文字列は、打ったまま登録します。
