## 選ぶ

| キー | すること |
| --- | --- |
| <kbd>Space</kbd>・<kbd>↓</kbd> | 次の候補。最後の次は [語の登録](/docs/usage/register/) |
| <kbd>Shift</kbd>＋<kbd>Space</kbd>・<kbd>↑</kbd> | 前の候補。最初の前は最後 |
| <kbd>Ctrl</kbd>＋<kbd>N</kbd>・<kbd>Ctrl</kbd>＋<kbd>P</kbd> | 次・前のページの最初の候補。最後のページの次は最初のページ <Since feature="candidate-pages" /> |
| <kbd>1</kbd>〜<kbd>9</kbd> | 出ているページの、その番号の候補を確定する |
| <kbd>Enter</kbd>・<kbd>Ctrl</kbd>＋<kbd>J</kbd> | 選んでいる候補を確定する |
| <kbd>;</kbd> | 選んでいる候補を確定して、次の読みを始める |
| 文字のキー | 選んでいる候補を確定して、その文字を打つ |
| <kbd>Esc</kbd>・<kbd>Ctrl</kbd>＋<kbd>G</kbd>・<kbd>Backspace</kbd> | 読みに戻る。読みは消さない |
| <kbd>Tab</kbd>・<kbd>Shift</kbd>＋<kbd>Tab</kbd> | 読みに戻って、[補完](/docs/usage/complete/) を続ける <Since feature="complete" /> |
| <kbd>0</kbd> | その読みで [語を登録する](/docs/usage/register/) |
| <kbd>Shift</kbd>＋<kbd>Delete</kbd> | 選んでいる候補を、以後出さない（もう一度押して確かめる） |

## 候補の一覧

候補は、番号と表記の一覧で、9 個ずつのページに分けて出ます。番号はページの中で 1 から振ります。候補が 1 つだけのときは、一覧を出しません。一覧の候補はマウスでも選べ、選んだ候補を確定します。

- ページが 2 つ以上あるときは、出しているページと全体のページ数を示します。<Since feature="candidate-pages" />
- 辞書から来た候補には、その辞書の名前を添えます。名前は、辞書の 1 行目の説明か、ファイルの名前です。<Since feature="candidate-pages" />
- OS の辞書で意味を引ける環境では、意味のある候補にそのことを示し、選んでいる候補の意味を一覧の横に出します。<Since feature="candidate-meanings" />

## カタカナや英数で確定する

候補の最後には、読みをカタカナ・半角カタカナ・全角英数・半角英数にしたものが付きます。英数は、読みを打ったキーから作ります（<kbd>kanji</kbd> → ｋａｎｊｉ・kanji）。

ファンクションキーなら、候補を回らずにすぐ確定できます。

| キー | 確定するもの | 例（<kbd>;kanji</kbd>） |
| --- | --- | --- |
| <kbd>F6</kbd> | ひらがな | かんじ |
| <kbd>F7</kbd> | カタカナ | カンジ |
| <kbd>F8</kbd> | 半角カタカナ | ｶﾝｼﾞ |
| <kbd>F9</kbd> | 全角英数 | ｋａｎｊｉ |
| <kbd>F10</kbd> | 半角英数 | kanji |
| <kbd>無変換</kbd> | カタカナを選ぶ（確定はしない） | »カンジ |

## 並び方

並べ替えのモデル（基本辞書と組の `ranking.model`）が設定のフォルダにあれば、候補をモデルの点数の順に並べます。モデルは、読みと表記、候補が来た辞書、この入力欄で確定した語と直前に確定した文字などから点数を付けます。モデルは、[設定アプリで基本辞書を入れる](/docs/dictionaries/#設定アプリで入れる) と一緒に入ります。

モデルには形式の版があり、Kanaemi の読める版と違うモデルは使いません。Kanaemi を新しくしたら、[設定アプリで基本辞書の新しい版を確かめて](/docs/dictionaries/#設定アプリで入れる)、あれば新しくしてください。

モデルがなければ、次の順に並べます。

1. この入力欄で、同じ読みに対して最後に確定した表記
2. この入力欄で確定したことのある表記
3. それ以外。辞書の優先度の順、同じ辞書の中ではよく使う語から

さらに、その入力欄でその読みをまだ確定していなければ、何度も選んできた候補が先頭に出ます。1 度選んだだけでは順は変わらず、古い選択ほど順への影響が小さくなります。

- 入力欄の中の記録（1・2）は、フォーカスが移ると捨てます。
- 何度も選んだ候補の記録は、[設定のフォルダ](/docs/settings/folder/) の `selections.tsv` に残ります（[ほかの場所にも置けます](/docs/settings/folder/#打った語を含むファイルをほかの場所に置く)）。読みと表記だけを残し、いつ選んだかは残しません。[設定アプリ](/docs/settings/app/) で消せます。
- パスワード欄と、ブラウザのプライベートウィンドウのように記録しないよう求める入力欄では、どちらの記録も取りません。

同じ読み・同じ記録なら、並びはいつも同じです。打つたびに順が変わることはありません。

### モデルを使わずに並べる

<Since feature="toggle-model" />

並びがおかしいと感じたら、モデルを使わずに並べて見比べられます。

- 候補を選んでいるときに <kbd>Ctrl</kbd>＋<kbd>R</kbd>（[`@toggle-model`](/docs/reference/functions/#並べ替えのモデルを切り替える)）を押すと、モデルを使うかどうかが切り替わり、選んでいる候補のまま並べ直します。切り替えは、Kanaemi が動いているあいだ、以後の変換にも効きます。
- 候補の一覧には、モデルで並べたかどうかを「モデルあり」「モデルなし」と示します。macOS と Windows では一覧の下に、Linux では一覧に添える文に出ます。
- 既定は、[設定ファイル](/docs/settings/config/) の `[ranking] model` で決めます。[設定アプリ](/docs/settings/app/#辞書) の「辞書」でも選べます。設定を変えると、その値に戻ります。
- モデルを使わないときは、モデルがないときと同じに並べます。

## 出さないようにする

<kbd>Shift</kbd>＋<kbd>Delete</kbd> で、選んでいる候補をその読みで以後出さないようにできます。どの辞書の候補にも使えます。

1. <kbd>Shift</kbd>＋<kbd>Delete</kbd> を押す。候補の後ろに、もう一度押すと除外することを示す文が出る。
2. もう一度 <kbd>Shift</kbd>＋<kbd>Delete</kbd> を押すと、その候補を以後出さない。

- 確かめている間に <kbd>Esc</kbd> を押すと、やめて候補を選ぶ場面に残ります。ほかのキーを押すと、やめてそのキーのふだんのはたらきをします。
- キーを押したままにして繰り返される入力は、もう一度押したことになりません。うっかり長押ししても消えません。
- 読みから作った候補（カタカナや英数）は、出さないようにできません。

戻すときは [設定アプリ](/docs/settings/app/#辞書) を使います。

## 確定した候補を選び直す

<Since feature="undo-commit" />

確定してから違う候補だったと気づいたら、何も打っていないときに <kbd>Shift</kbd>＋<kbd>Backspace</kbd> を押します。直前に確定した候補が、候補を選ぶ場面に戻ります。読み・候補の並び・選んでいた候補は、確定したときのままです。

```
;kakuchou → »格調 を確定 → Shift+Backspace → »格調 → Space → »拡張
```

<Screencast name="undo-commit" alt=";kikan を変換して Enter で確定したあと、Shift+Backspace で候補を選ぶ場面に戻し、Space で次の候補を選んで確定し直す" />

- 戻せるのは、確定したあとに Kanaemi が出した文字だけが続いている間です（「格調する」の「する」は、候補の後ろに戻ります）。ほかのキーがアプリに渡ったとき、入力欄を移ったとき、マウスのボタンを押したときには戻せなくなります。
- 戻せるのは、変換して確定した最後の 1 語だけです。読みをかなのまま確定したものと、登録して確定したものは戻せません。
- 戻したあとは、ふつうの候補・読みの場面と同じに選び直せます。<kbd>Esc</kbd> を押すと、元の文字列を確定し直して終わります。
- 取り消した確定は、[並び方](#並び方) の記録からも外します。
- 戻せる確定がないときの <kbd>Shift</kbd>＋<kbd>Backspace</kbd> は、ふつうにアプリへ渡ります。

<kbd>;</kbd> を打ち忘れて、かなのまま打ってしまったときは [打ったかなを読みに戻す](/docs/usage/convert/#打ったかなを読みに戻す) を使います。

入力欄の文字を消すために、Kanaemi がアプリに <kbd>Backspace</kbd> を送ります。macOS では、アクセシビリティの許可が要ります（[インストール](/docs/install/#macos-の許可)）。許可がないときは戻さず、キーをそのままアプリに渡します。
