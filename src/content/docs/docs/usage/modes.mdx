Kanaemi のモードは 2 つだけです。

| モード | すること |
| --- | --- |
| ABC モード | 英字をそのまま打つ |
| かなモード | ローマ字でかなを打ち、その場で確定する（<kbd>watashiha</kbd> → わたしは） |

カタカナモードや全英モードはありません。カタカナや英数にしたい語は、[確定するときに選びます](/docs/usage/candidates/#カタカナや英数で確定する)。

## 切り替える

<ThemedFigure name="shift" alt="左の Shift だけをポンと押して離すと ABC モード、右の Shift だけを押して離すとかなモードになる" />

<Screencast name="modes" alt="かなモードで koreha と打つと「これは」が入る。左の Shift を単独で押すと ABC モードになり、Kanaemi と英字で入る。右の Shift を単独で押すとかなモードに戻り、desu. で「です。」が入る" />

| キー | 結果 |
| --- | --- |
| 右の <kbd>Shift</kbd> を単独で押す・<kbd>かな</kbd>・<kbd>変換</kbd> | かなモードへ |
| 左の <kbd>Shift</kbd> を単独で押す・<kbd>英数</kbd>・<kbd>無変換</kbd> | ABC モードへ |
| 何も打っていないときの <kbd>Esc</kbd> | キーをアプリに渡して、ABC モードへ |
| かなモードで大文字を打つ | ABC モードへ切り替えて、その大文字を打つ（[下を見る](#大文字で-abc-モードへ)） <Since feature="abc-on-capital" /> |

「単独で押す」は、<kbd>Shift</kbd> だけを押して、ほかのキーを押さずに離すことです。<kbd>Shift</kbd> を押さえたまま文字を打つと単独押しにはならず、大文字を打ちます。押してから離すまでが 300 ミリ秒を超えると、単独押しになりません。この長さは [設定で変えられます](/docs/settings/keys/#修飾キー)。

押す側でモードが決まるので、今どちらのモードかを気にしなくても、打ちたいモードに入れます。

打っている途中で ABC モードにすると、読みはかなのまま確定し、候補は選んでいるものを確定してから、ABC モードに切り替わります。

## 大文字で ABC モードへ

<Since feature="abc-on-capital" />

かなモードで大文字を打つと、ABC モードに切り替わって、その大文字が入ります。英語の語を打ち始めるときに、先にモードを切り替えなくて済みます（<kbd>Shift</kbd>＋<kbd>K</kbd> から <kbd>anji</kbd> と打つと Kanji）。

- 何も打っていないときと、[登録する文字列](/docs/usage/register/) を打っているときに働きます。ローマ字の打ちかけがあれば、確定してから切り替えます。
- 読みや候補の場面では切り替えません。読みの中の大文字は、そのまま読みに入ります。
- ローマ字の表が使う大文字と、[キーバインド](/docs/settings/keys/) で機能を割り当てた大文字は、そちらが働きます。
- <kbd>Caps Lock</kbd> をかけたまま打っても切り替わります。

切り替えたくないときは、[設定アプリ](/docs/settings/app/) の「入力」で「大文字で ABC モードへ」を切るか、[設定ファイル](/docs/settings/config/) に次のように書きます。

```toml
[keys]
abc_on_capital = false
```

## モードの表示

モードが切り替わったときだけ、カーソルの近くに「かな」「ABC」が短く出ます。[設定ファイル](/docs/settings/config/) の `mode_indicator = false` で出さないようにもできます。

Linux では、IBus や Fcitx5 のパネルが表示を描きます。IBus 版では、モードの表示は GNOME でだけ出ます。Fcitx5 版では、Fcitx5 のパネルが小さな札で出します。

## 入力欄とモード

- 入力欄にフォーカスが入ると、ABC モードから始まります。
- パスワード欄では、かなモードに入りません。

エディタなどから、今のモードを知ったり変えたりもできます。[外からの操作](/docs/integrations/control/) を見てください。
