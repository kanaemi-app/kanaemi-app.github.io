Kanaemi のモードは 2 つだけです。

| モード | すること |
| --- | --- |
| ABC モード | 英字をそのまま打つ |
| かなモード | ローマ字でかなを打ち、その場で確定する（`watashiha` → わたしは） |

カタカナモードや全英モードはありません。カタカナや英数にしたい語は、[確定するときに選びます](/docs/usage/candidates/#カタカナや英数で確定する)。

## 切り替える

<ThemedFigure name="shift" alt="左の Shift だけをポンと押して離すと ABC モード、右の Shift だけを押して離すとかなモードになる" />

| キー | 結果 |
| --- | --- |
| 右の <kbd>Shift</kbd> を単独で押す・<kbd>かな</kbd>・<kbd>変換</kbd> | かなモードへ |
| 左の <kbd>Shift</kbd> を単独で押す・<kbd>英数</kbd>・<kbd>無変換</kbd> | ABC モードへ |
| 何も打っていないときの <kbd>Esc</kbd> | キーをアプリに渡して、ABC モードへ |

「単独で押す」は、Shift だけを押して、ほかのキーを押さずに離すことです。Shift を押さえたまま文字を打つと、ふつうに大文字になります。押してから離すまでが 300 ミリ秒を超えると、単独押しになりません。この長さは [設定で変えられます](/docs/settings/keys/#修飾キー)。

押す側でモードが決まるので、今どちらのモードかを気にしなくても、打ちたいモードに入れます。

打っている途中で ABC モードにすると、読みはかなのまま確定し、候補は選んでいるものを確定してから、ABC モードに切り替わります。

## モードの表示

モードが切り替わったときだけ、カーソルの近くに「かな」「ABC」が短く出ます。[設定ファイル](/docs/settings/config/) の `mode_indicator = false` で出さないようにもできます。

Linux（IBus）では、IBus のパネルが表示を描きます。モードの表示は GNOME でだけ出ます。

## 入力欄とモード

- 入力欄にフォーカスが入ると、ABC モードから始まります。
- パスワード欄では、かなモードに入りません。

エディタなどから、今のモードを知ったり変えたりもできます。[外からの操作](/docs/integrations/control/) を見てください。
